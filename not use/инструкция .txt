==========================================================
ИНСТРУКЦИЯ ПО РАБОТЕ С ИНСТРУМЕНТАМИ ДЛЯ ИГРЫ WARLOCK
(Warlock — Master of the Arcane) + Warlock 2
==========================================================

ОБЩИЕ СВЕДЕНИЯ
----------------------------------------------------------
В этой папке лежит набор утилит для распаковки, конвертации
и повторной упаковки файлов игры Warlock — Master of the
Arcane от Paradox Interactive.

Отдельного файла документации (README или .md) в папке НЕТ.
Все пояснения, которые удалось найти, находятся в виде
комментариев внутри BAT-файлов (скриптов Windows).

Набор утилит заточен под работу с ТРЕМЯ типами файлов:

1) .pack — игровые архивы (сжимаются/распаковываются
утилитой Squeezer.exe)
2) .xr — текстовые контейнеры (локализация, данные),
конвертируются утилитой XRconvert_Final.exe
3) .binary — бинарные файлы данных, конвертируются
утилитой TXMLConvert.exe

СПИСОК ФАЙЛОВ И ИХ НАЗНАЧЕНИЕ
----------------------------------------------------------

ИСПОЛНЯЕМЫЕ ФАЙЛЫ И БИБЛИОТЕКИ:
Squeezer.exe — упаковка/распаковка .pack-архивов
XRconvert_Final.exe — конвертация .xr <-> .xml
TXMLConvert.exe — конвертация .binary <-> .xml
BMCore.dll — служебная библиотека
msvcp110.dll — служебная библиотека (Microsoft)
msvcr110.dll — служебная библиотека (Microsoft)

ВАЖНО: библиотеки .dll должны лежать в той же папке,
что и утилиты, иначе программы не запустятся.

BAT-СКРИПТЫ (обёртки для удобства запуска):

1. w2extract.bat — ПОЛНЫЙ ЦИКЛ РАСПАКОВКИ.
Находит все файлы .pack, .xr и .binary в текущей
папке и всех подпапках, распаковывает их в подпапку
w2extract\, а лог работы пишет в файл w2extract.txt.

Что именно делает по шагам:
- .pack -> создаёт папку с именем архива
- .xr -> конвертирует в .xml
- .binary -> конвертирует в .xml (в кодировке UTF-8)

2. Decompile.bat — ПОЛНЫЙ ЦИКЛ РАСПАКОВКИ (вариант 2).
Делает то же самое, но распаковывает файлы НЕ в
отдельную подпапку w2extract\, а прямо РЯДОМ с
исходными файлами (в корень данных, папка "\").

3. bin2xml.bat — только .binary -> .xml (UTF-8).
Полезна, если нужно распаковать только бинарные файлы.

4. xml2binary.bat — только .xml -> .binary (обратная
конвертация бинарных файлов).

5. xr2xml.bat — только .xr -> .xml.
Полезна для локализации.

6. xml2xr.bat — только .xml -> .xr (обратная
конвертация .xr-файлов).

7. Compile.bat — упаковывает папку d179+ в архив
d179.pack. Используется для СБОРКИ мода.

8. Compile+.bat — сначала конвертирует все .xml из
указанной папки в .binary, затем упаковывает папку
в .pack. Полный цикл сборки мода.

ЛОКАЛИЗАЦИЯ (locdata.xr)
----------------------------------------------------------
В папке лежит файл locdata.xr — это и есть файл локализации
игры Warlock. В нём содержатся все игровые строки/тексты.

Формат .xr — это «сырой» контейнер, читать его напрямую
текстовым редактором нельзя. Чтобы получить читаемый XML,
нужно запустить конвертацию:

xr2xml.bat -> locdata.xr -> locdata.xml

Либо запустить полный цикл распаковки:

w2extract.bat или Decompile.bat

Они автоматически найдут все файлы *.xr и превратят их в
*.xml, внутри которых будут видны локализованные строки.

После того, как вы отредактировали текст в XML, файл нужно
вернуть в формат игры:

xml2xr.bat -> .xml -> .xr

(а для бинарных данных вместо этого используется
xml2binary.bat — смотря какой формат ожидает игра).

ПРО ОТКРЫТИЕ ФАЙЛОВ MD
----------------------------------------------------------
1) Если под «MD» вы имели в виду Markdown-файлы (.md),
то таких в папке нет — документации в формате Markdown
не прилагалось.

2) Если «MD» — это какой-то внутренний формат файлов игры
Warlock (например, нестандартное расширение внутри
.pack-архивов), то отдельной утилиты именно под *.md в
этом наборе НЕТ. Набор работает только с тремя типами:
.pack, .xr, .binary.

ИТОГОВЫЙ ПОРЯДОК РАБОТЫ (краткая схема)
----------------------------------------------------------

РАСПАКОВКА:
запустите w2extract.bat (или Decompile.bat)
-> получите распакованные папки и читаемые .xml файлы

ПРАВКА:
редактируйте полученные .xml в любом текстовом редакторе
(например, Notepad++). Для локализации правим locdata.xml.

СБОРКА:
запустите Compile.bat или Compile+.bat
-> получите готовый .pack файл для подстановки в игру.

ПРИМЕЧАНИЯ
----------------------------------------------------------
- Все BAT-скрипты рассчитаны на Windows и должны запускаться
из папки, где лежат файлы игры (или из папки с данными).
- Скрипты используют цикл FOR /R, то есть обрабатывают файлы
рекурсивно, включая все вложенные подпапки.
- Путь к установленной игре в одном из скриптов указан как:
C:\Program Files (x86)\Paradox Interactive\
Warlock - Master of the Arcane\
(эта строка закомментирована словом rem — при необходимости
можно раскомментировать и поправить под свой путь).

КОНЕЦ ИНСТРУКЦИИ
==========================================================

или 

Такая большая инструкция не нужна, всё проще:

Распаковка файлов игры
1. Скопировать pack-файл архива (родной из игры или файл мода) в папку тулкита
2. Запустить Decompile.bat. Утилита создаст папку с именем pack-файла, где будут лежать файлы из архива

Изменить по вкусу xml или dds

Запаковка измененных файлов в архив
1. Запустить Compile.bat с параметром - именем папки, например, Compile.bat d180. Утилита создаст pack-файла архива, где будут лежать файлы из папки
2. Скопировать получившийся pack-файл архива в папку игры

А вот в Warlock 1 файл локализации в специфичном формате md, сигнатура mdmp.
